# Перевірка «Перед дорогою» · 0.10.2+19

[Реліз v0.10.2-beta.19](https://github.com/DimasikBog/AMID-Offgrid/releases/tag/v0.10.2-beta.19)
зібраний з `19aa09b7ee241ac2d5677cbf559676e8e491208a`.
Вебверсія — з `b1d24d03c50f6574ea3ab06ab418e37ce244a028`.
Між ними додані лише Arduino-матеріали `hardware/azimuth`, його workflow і
посилання README; вихідний код та конфігурації додатка збігаються.
Список усіх 49 змінених шляхів звірено через GitHub compare.

- Flutter 3.47.6 / Dart 3.13.5: аналізатор без зауважень; 205 Flutter-тестів
  успішні. Два мережеві smoke-сценарії пропущені за замовчуванням.
- 26 Python-перевірок і 9 серверних Node-тестів успішні.
- Нові UI-тести: 320 px, текст 100%/200%, атлас не зараховується як вулиці,
  зміни області оновлюють екран, дії карти/набору працюють, SOS відкривається
  з тренуванням. Перевірено відкриття зі справжнього меню OffgridShell.
- Прямий перехід до області перевірений у UI-тестах із реальним SQLite:
  локальний street-provider, очищення попереднього вибору MBTiles, збережений
  режим і лише один перехід після швидкого подвійного натискання.
- Ізольований Chromium: завантаження PWA, вимкнення мережі, відкриття нового
  огляду, коректне обмеження GGUF у web, перехід до тренування SOS. Знімок
  екрана телефона переглянутий; викликів/SMS у сценарії немає.
- [Браузерна CI-перевірка](https://github.com/DimasikBog/AMID-Offgrid/actions/runs/45824412139)
  успішна: встановлення/офлайн/PWA-оновлення та 13 Chrome-тестів метаданих,
  захисту профілю, радіоформатів і збережених вулиць.
- [Усі 8 платформних збірок](https://github.com/DimasikBog/AMID-Offgrid/actions/runs/45826385807)
  та [Android/iOS/Wear OS/watchOS](https://github.com/DimasikBog/AMID-Offgrid/actions/runs/45824412288)
  успішні. Телефонний сценарій додатково перевіряє меню → «Перед дорогою» →
  карта, потім попереднє тренування SOS, локальну ШІ й відновлення даних.
- 8 маніфестів і 9 пакетів звірені за версією, build, джерелом, розміром
  та SHA-256 з публічних digest GitHub. Байти маніфестів перевірено окремо.
  Метадані живої вебверсії підтверджують 0.10.2+19; її код звірений із релізом.

Комп’ютерна macOS-збірка використовує `macos-15-intel` з попереднім Xcode
26.2. Попередню ARM-спробу GitHub скасував до запуску через нестачу виконавців.
Виконавці iOS/watch не змінені. `BUILD_ARCHITECTURE.txt` у macOS-пакеті
тепер містить `lipo`-архітектури виконуваного файла, а не лише тип хоста.

Android-збірка потребувала повтору через HTTP 429 від Maven під час отримання
Kotlin-залежності. Після повтору без зміни коду Android вона успішна.

Огляд читає записи сховища, не є аудитом байтів файлів, тестом мобільної мережі
або підтвердженням екстреної допомоги. Фізичні телефони, жива локальна ASR,
справжні дзвінки/SMS, доставлення службам і магазини не перевірялися.
iOS-пакет без підпису. Дані, дозволи й формати копій цим етапом не змінені.
