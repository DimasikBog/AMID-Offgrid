# AMID Offgrid 0.5.0+7 — перевірка кандидата

Дата: 24 листопада 2026 року. Цей запис описує перевірки вихідного коду,
а не готовність до магазинів або встановлення на фізичний пристрій.

## Підтверджено локально

- Flutter 3.47.6, Dart 3.13.5; офіційний SDK перевірено SHA-256.
- `flutter pub get --enforce-lockfile`: успішно; 135 зафіксованих пакетів,
  версії залежностей попереднього випуску збережено. `sqflite_common_ffi`
  переведено з тестової залежності до виконуваної для Windows/Linux.
- `flutter analyze --no-pub`: без зауважень.
- `flutter test --no-pub --concurrency 1`: **112 тестів успішно**.
- Python unittest: **8 тестів успішно**.
- actionlint 1.7.7: перевірка YAML GitHub Actions успішна.
- Візуально переглянуто еталонні зображення реального інтерфейсу:
  телефон 390×844, комп'ютер 1440×900 з темною темою та екран 320×480
  зі збільшенням тексту 2×. Прокручування потрібне для вмісту нижче екрана.
- Перевірки охоплюють збереження налаштувань і резервну копію, атомарне
  відхилення некоректних даних, чергу записів, FFI SQLite, режим Lite,
  копіювання тексту, клавіатурну навігацію та адаптивний інтерфейс.
- Roboto і його OFL включено в пакет; SHA-256 та походження в
  `assets/fonts/provenance.json`. Український текст не потребує Google Fonts.

## Потрібно перевірити через Actions

Нові Android, iOS, Windows, Linux, macOS, Wear OS, watchOS і web пакети
повинні отримати маніфести з точною ревізією вихідного коду, розміром та
SHA-256 кожного файлу. Для нових нативних завдань потрібен public-репозиторій.
Наявність конфігурації CI не означає успішної компіляції.

Windows/Linux мають додатковий запуск з `--self-test`, який перевіряє
SQLite, повторне відкриття даних і пошук в окремій тимчасовій директорії.
macOS та годинники наразі перевіряються компіляцією; фізичної перевірки немає.
Автоматична публікація кандидата дозволена лише після всіх восьми платформ.

## Ще не підтверджено

- Встановлення та повсякденна робота на фізичних пристроях.
- Робота BLE, GPS, моделей GGUF, GPU та карт на кожній desktop-платформі.
- Офлайн-перезапуск PWA у Safari/Chrome після першого завантаження,
  очищення/квоти сховища та оновлення встановленої PWA.
- Власний стабільний Android/Wear OS ключ для оновлень між випусками.
- Підписування iOS/watchOS, Apple notarization, Microsoft code signing.
- Синхронізація нотаток і обраного з годинником: не реалізована.
- App Store / Google Play: політики, облікові записи, фізичні тести,
  конфіденційність, скриншоти й подання залишаються відкритими.

Lite — режим основної програми, він не зменшує розмір її APK.
AMID Pocket — окремі невеликі нативні програми годинників із вбудованими
картками та локальним контрольним списком. Підтримка інших ОС годинників
не заявляється. Непідписані Apple-пакети не є готовими інсталяторами.
