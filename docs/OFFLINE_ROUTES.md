# Офлайн-маршрути 0.4.1

Карта → кнопка маршруту → мережа → початок і кінець → «Побудувати маршрут» →
«Показати на карті». На карті є відстань, точки A/B, центр маршруту,
експорт GeoJSON та очищення поточного результату.

Мережа зберігається як пакет без обов’язкових статей. Її можна видалити в
пакетах, перенести через резервну копію та відновити. Поточний результат не
зберігається окремо: його можна знову обчислити або експортувати як GeoJSON.

## Підготовка даних

Імпортуй [route_network.json](../examples/route_network.json) у «Пакетах» для
перевірки інтерфейсу. Це **синтетична навчальна мережа біля координат 0,0**;
вона не описує справжні дороги й не встановлюється автоматично. A → C іде
через B; C → A використовує довший обхід через односторонню B → C. Пункт D
від’єднаний, тому маршрут до нього не будується.

Для власних даних створи JSON-пакет AMID версії 1 з унікальним id, title,
license, articles (може бути порожнім) та полем routing:

```json
{
  "format": "AMID_ROUTE_NETWORK",
  "version": 1,
  "synthetic": false,
  "nodes": [
    {"id": "a", "name": "Початок", "coordinate": [22.0, 48.0]},
    {"id": "b", "name": "Кінець", "coordinate": [22.001, 48.0]}
  ],
  "edges": [
    {
      "id": "ab", "from": "a", "to": "b", "name": "Назва ділянки",
      "bidirectional": false, "via": []
    }
  ]
}
```

Координати — довгота, широта, WGS84 у градусах. Координати вище є прикладом
синтаксису, а не підтвердженим шляхом. via — проміжні координати від from до to;
кінцеві точки беруться з nodes. bidirectional є обов’язковим boolean: false
дозволяє лише from → to, true — обидва напрямки. synthetic також обов’язковий;
навчальні дані позначаються на екранах та в експорті.

Зв’язність визначається **ID вузлів**, а не перетином ліній чи близькістю
координат. Міст і дорога під ним не з’єднаються автоматично; для переходу між
шляхами потрібен спільний вузол. Не з’єднуй різні рівні однаковими ID.
Відсутні посилання, дублікати ID, петлі from=to, NaN, нульова довжина та
неприпустимі типи відхиляються до активації пакета.

Одна мережа: 2–10 000 вузлів, 1–30 000 ділянок, до 100 000 проміжних точок.
Діють чинні обмеження розміру текстового імпорту та сховища. Ділянки з
переходом довготи понад 180° через антимеридіан відхиляються.

## Обчислення та експорт

Вага ділянки — сума сферичних відстаней між її послідовними координатами
(середній радіус Землі 6 371 008,8 м). Dijkstra з мінімальною купою знаходить
найменшу сумарну відстань, включно з паралельними й односторонніми ділянками.
За відсутності шляху показується помилка; пряма лінія замість нього не
підставляється. На native RouteWorker керує окремим isolate: скасування,
зміна завдання, закриття екрана або згортання застосунку закривають канал і
надсилають запит на завершення воркера. У web розрахунок працює в основному
потоці: завдання можна скасувати до старту, а синхронний розрахунок посеред
виконання не переривається. Застарілі результати не показуються.

Після появи панелі маршрут центрується з урахуванням нового розміру карти.
На коротких екранах і з великим шрифтом доступна вертикальна прокрутка зі
смугою прокручування; саму карту можна далі переміщати жестами.

GeoJSON містить всю впорядковану геометрію, відстань, ID вузлів і ділянок,
назву джерела, ліцензію та synthetic. Формат координат і LineString описаний у
[RFC 7946](https://www.rfc-editor.org/rfc/rfc7946). Експорт містить відкриті
координати. Повторний імпорт GeoJSON додає лінію для відображення; мережу він не
відновлює — для неї використовуй оригінальний AMID JSON або backup.

## Межі

MBTiles — картографічні зображення, а звичайний GeoJSON — геометрія. Вони не
конвертуються автоматично в мережу. Немає імпорту OSM/PBF, адресного пошуку,
GPS-прив’язки до найближчого ребра, ETA, голосових підказок, автомобільного
профілю та дорожніх обмежень. Постачальник даних має включити потрібні зв’язки
й напрямки; застосунок не визначає право доступу чи фізичну прохідність.

Автотести перевіряють алгоритм, валідацію, імпорт, SQLite/backup та UI. Реальні
місцеві дані, GPS, обмін файлами й приймання на Android/iPhone залишаються
відкритими перевірками.
