# Перевірка 0.9.0+16

Локальне середовище: офіційні Flutter 3.47.6 / Dart 3.13.5, Linux,
ізольований Chromium Headless 151.0.7922.34. Фізичні телефони не перевірялися.

- `flutter analyze --no-pub`: без зауважень.
- `flutter test --no-pub --concurrency 2 --reporter expanded`: 192 успішні тести;
  мережеві smoke-сценарії запускаються окремо за `AMID_LIVE_MAP=1`.
- `python3 scripts/check_project.py`, `python3 scripts/check_radio_hardware.py`:
  версії, ідентичність та попередні апаратні розрахунки збережені.
- 24 Python-тести, 9 серверних Node-тестів: успішно.
- `scripts/check_catalog_browser.py`: 13 успішних Chrome-тестів, включно з
  читанням справжнього MVT з IndexedDB після повторного відкриття, перевіркою
  SHA-256, розділенням атласу/вулиць, прибиранням сиріт і межами тайлів у JS.
- Release web build (без зовнішнього CDN ресурсів Flutter) успішний.
- `scripts/check_web_browser.py`: встановлення PWA, офлайн-корінь/глибокі
  посилання, відновлення втраченого ресурсу, оновлення з іншою вкладкою та
  відхилення пошкодженої заміни успішні в Chromium.
- Справжні MVT поблизу Велима: дороги, будівлі та назви перевірені через
  rendered-feature query та візуально переглянуті goldens світлої класики й
  темного кіберпанку. Звичайні тести використовують ліцензовані локальні
  fixtures і не залежать від доступності публічних серверів.
- 320/768/1440 px з текстом 200%: вибір стилю доступний, переповнення немає.
  Збереження палітри в резервній копії та ізольованих зашифрованих профілях
  перевірене разом з попередніми сценаріями офлайн-входу.

Пакети для нативних платформ і публікація Pages перевіряються окремими
GitHub Actions цього коміту. Цей файл не засвідчує запуск нового релізу
на фізичному iPhone/Android або роботу всіх можливих OSM-об’єктів світу.
Голосова навігація, автоматичний офлайн-перерахунок по загальному OSM-графу,
поточні перекриття та повний офлайн-індекс усіх адрес не додані.
