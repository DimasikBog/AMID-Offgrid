# Дані та приватність AMID Offgrid 0.3.0

Застосунок не потребує облікового запису AMID. Матеріали, нотатки, обране,
чернетка, точки й повідомлення зберігаються на пристрої. Живе локальне сховище
не захищене окремим паролем застосунку. Доступ до розблокованого пристрою дає
доступ до цих даних.

GGUF-модель виконує запити на пристрої. Для її початкового завантаження
використовується Hugging Face; цей зовнішній сервер отримує звичайні мережеві
дані завантаження, зокрема IP-адресу. Тексти запитів помічника не надсилаються
до модельного сервера. Користувач може імпортувати модель самостійно.

Bluetooth передає вибрані повідомлення сполученому співрозмовнику. Код
сполучення містить секрет сеансу. Функція «Поділитися» передає вибраний текст
іншому застосунку за дією користувача. Власні координати потрапляють у текст
повідомлення лише після відповідної дії користувача.

Камера потрібна для QR, геолокація — для кнопки GPS, доступ до Bluetooth —
для прямого зв’язку. Відмова в цих дозволах не повинна блокувати довідник.
Фоновий mesh або безперервний фоновий запис геолокації не реалізовані.

Звичайний JSON-експорт відкритий. Копія з паролем шифрує текстові дані, точки,
повідомлення, обране та чернетку; пароль не зберігається. Без пароля таку копію
відкрити не вдасться. GGUF і MBTiles до резервної копії не входять. GeoJSON-
експорт точок є відкритим файлом із координатами.

Матеріали, власні нотатки, точки та повідомлення можна видалити в застосунку.
Видалення застосунку прибирає його локальне сховище згідно з поведінкою ОС;
експортовані копії й оригінали файлів користувач видаляє окремо. Автоматичну
системну резервну копію каталогу AMID вимкнено/виключено конфігурацією платформ.

підтверджені. Наявність цього файла не означає проходження перевірки магазину.
