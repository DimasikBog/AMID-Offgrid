# AMID Offgrid 0.6.1 — дизайн і навігація

25 листопада 2026 року. Продовження наявного Flutter-застосунку 0.6.0+8.

## Що змінилося

- Темно-зелена головна картка зі статичними контурними лініями. Декор не
  завантажує карти, не звертається до GPS і не виконує анімацій.
- Теплий світлий фон, білі картки, узгоджена темна тема, виразніші заголовки,
  спільні відступи та окремий акцент кожного з чотирьох розділів.
- Пошук із головної відкриває бібліотеку й одразу фокусує поле введення.
- Лічильник обраного відкриває всі обрані статті, скидаючи попередній запит
  і категорію. Повторний перехід працює також після ручної зміни фільтра.
- Основні розділи розміщені перед додатковими швидкими діями. На широкому
  екрані — чотири картки, на телефоні — дві; при великому шрифті на вузькому
  екрані — одна. Висота залежить від тексту, без обрізання описів.
- Оновлене оформлення бібліотеки, контрасти попереджень у світлій темі,
  український шрифт бічної навігації та видима кнопка теми на широкому екрані.
- Компактне компонування бібліотеки на короткому екрані; пошук втрачає
  фокус при виході з вкладки, щоб екранна клавіатура не залишалася поверх головної.

Наявні статті, нотатки, резервні копії, карта, локальний помічник та засоби
зв’язку використовують попередні сервіси. Формат сховища не змінювався.
Годинники отримують спільний номер версії; їхній інтерфейс у цьому етапі не змінено.

## Локальні перевірки

Команди виконуються зі стабільним Flutter 3.47.6 / Dart 3.13.5 та зафіксованими
залежностями. Конкретні результати наведено в PR цього оновлення.

```sh
flutter pub get --enforce-lockfile
python3 scripts/check_project.py
python3 -m unittest discover -s scripts -p 'test_*.py'
dart format --output=none --set-exit-if-changed lib test
flutter analyze --no-pub
flutter test --no-pub --concurrency 2 --reporter expanded
flutter build web --release --no-pub --no-web-resources-cdn --base-href /AMID-Offgrid/
python3 scripts/build_web_cache.py build/web
```

Візуальні еталони головної оновлено та переглянуто: 390×844 (світла тема),
1440×900 (темна) та 320×480 з масштабом тексту 200%. Автоматичний сценарій
додатково перевіряє фокус пошуку та повторне відкриття обраного після зміни
фільтрів. Це не нова перевірка фізичних пристроїв і не підписаний iOS-реліз.
