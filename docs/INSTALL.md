# Встановлення AMID Offgrid 0.5

Пакети публікуються в GitHub Releases як **тестові кандидати** після успішної
збірки всіх восьми платформ одним workflow. Вихідний код — під MIT; сторонні
компоненти й власні імпортовані матеріали зберігають свої ліцензії.

Завантажуй пакет зі сторінки конкретного релізу, а не старий `latest`:
GitHub не завжди вважає beta-реліз найновішим стабільним. Поряд із файлами є
`*-manifest.json` із версією, source commit і SHA-256. Не змішуй пакети різних
версій. Перед оновленням експортуй резервну копію; карти та GGUF збережи окремо.

| Пристрій | Пакет і спосіб | Межі кандидата |
| --- | --- | --- |
| Android | `AMID_Offgrid_android_arm64.apk`, особисте встановлення APK | Android 8+, ARM64; development-підпис, не Google Play |
| iPhone / iPad | `AMID_Offgrid_iOS_unsigned.ipa`, власний підпис за SIGNING.md | iOS 17+; unsigned IPA не встановлюється простим натисканням |
| Windows | `AMID_Offgrid_Windows_x64.zip`, розпакувати все й відкрити `amid_offgrid.exe` | Windows 10/11 x64; потрібен системний Microsoft Visual C++ runtime, підпис видавця відсутній |
| Linux | `AMID_Offgrid_Linux_x64.zip`, розпакувати все, запустити `./amid_offgrid` | Збірка Ubuntu 24.04 x64, GTK3/OpenGL і системні бібліотеки; інші дистрибутиви перевіряються окремо |
| macOS | `AMID_Offgrid_macOS.zip`, повна `.app` і файл BUILD_ARCHITECTURE.txt | macOS 14+; unsigned, без notarization; потрібен належний процес довіри/підписування |
| Wear OS | `AMID_Pocket_WearOS.apk`, встановлення на власний годинник через Android platform-tools | Wear OS 3+ / API 30+, окремий package ID; без Flutter, ШІ й карт |
| Apple Watch | `AMID_Pocket_watchOS_unsigned.zip`, watch-only SwiftUI `.app` | watchOS 10+; це unsigned-кандидат, процес особистого встановлення ще потрібно перевірити |
| Браузер | `AMID_Offgrid_Web.zip`, розпакувати на HTTPS-сервер або localhost | PWA; перше завантаження з мережею, браузерне сховище; без GGUF/BLE/MBTiles |

Файли з ZIP для комп’ютера мають залишатися разом: один EXE або одна бібліотека
без сусідніх `data/` і DLL/so не є повним застосунком. macOS ZIP зберігає
структуру framework і symlink через `ditto`.

## Windows

1. Розпакуй ZIP у власну папку та збережи її цілком.
2. Відкрий `amid_offgrid.exe`. Якщо бракує Visual C++ runtime, використовуй
   офіційний Microsoft Visual C++ Redistributable, сумісний із x64.
3. Зручність: Ctrl+K — пошук, Ctrl+N — нотатка, Alt+1…5 — основні вкладки.

На macOS для пошуку й нотаток використовуй ⌘ K / ⌘ N, для вкладок — ⌘ 1…5.

Прямий BLE-чат у цій версії увімкнено лише для Android/iPhone; desktop
залишає доступними чернетки. Наявність Bluetooth у комп’ютері цього не змінює.

Ця версія не має MSI-інсталятора, автооновлення або власного магазинного
підпису. Не вимикай системні засоби перевірки програм заради запуску кандидата.

## Wear OS

Увімкнення developer mode, налагодження й сполучення виконуються власником
на його годиннику. Після налаштованого офіційного ADB-з’єднання:

```sh
adb -s WATCH_SERIAL install -r AMID_Pocket_WearOS.apk
```

Заміни WATCH_SERIAL на серійний номер саме свого пристрою. APK має
`com.amid.offgrid.wear` і не замінює телефонний застосунок. У мініверсії є
шість коротких офлайн-карток та особистий чеклист. Позначки локальні; перенесення
обраного й синхронізації з телефоном поки немає. Це не екстрений маяк.

Звичайний APK не працює на Apple Watch, Garmin, Tizen та довільних закритих
годинниках. Для Apple Watch створено окремий SwiftUI-код, а не Flutter-екран.
Наявність `.app` після компіляції не підтверджує підписування або встановлення.

## Браузер і PWA

На HTTPS або localhost браузер може запропонувати «Встановити застосунок».
Офлайн-файли завантажуються під час першого відкриття. Дочекайся завантаження,
закрий і відкрий застосунок знову, потім перевір його без мережі. Кешування
залежить від дозволеного місця та політик браузера; фізична перевірка ще потрібна.
Очищення даних сайту може видалити матеріали — використовуй резервну копію.

Збірка для власного хостингу:

```sh
flutter build web --release --no-web-resources-cdn
python3 scripts/build_web_cache.py build/web
```

Для підкаталогу додай правильний `--base-href /назва/`. Автоматичне розгортання
на GitHub Pages не налаштоване: ZIP є готовим статичним пакетом, а не URL сайту.

## Що перевірено, а що потребує пристрою

Фактичні CI-результати дивись у workflow саме source commit із маніфесту.
Windows/Linux probe `--self-test` перевіряє тимчасову SQLite-базу, пошук,
масштаб і чеклист, не торкаючись особистих даних. Це не повний тест вікна,
моделі, GPS, BLE або Files. На macOS і годинниках компіляція не є device-тестом.

Перед оголошенням підтримки пристрою запиши його модель/ОС, SHA-256 пакета,
запуск, перезапуск, імпорт, резервну копію й помилки. Фінальні підписи,
оновлення без втрати даних і магазини залишаються окремими умовами.

Першоджерела: https://docs.flutter.dev/platform-integration/desktop,
https://developer.android.com/training/wearables/get-started/creating,
https://developer.apple.com/watchos/ .
