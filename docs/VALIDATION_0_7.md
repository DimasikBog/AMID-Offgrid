Нові регресії перевіряють HTTPS-політику адрес/посилань/redirect, інертний HTML,
межі DOM/тексту/пакета, HTTP/MIME/byte-limit відмови, plain text, скасування
очікування заголовків/тіла, timeout і заміну запиту. Зберігання перевірене
реальним тимчасовим SQLite: reopen, FTS, оновлення без дублікатів, обране,
видалення й merge резервної копії. UI-тест збереження використовує фікстуру
читача, а HTTP-reader має окремі транспортні тести; це не фізичний network-тест
на телефоні або перевірка будь-якого зовнішнього сайту.

Web release містить попередження про відсутній шрифт CupertinoIcons, на який
посилаються залежності. Збірка завершується успішно; власний UI використовує
вбудовані Roboto/MaterialIcons. Це не прихована помилка або новий результат
перевірки всіх сторонніх компонентів.

Workflow Web offline browser checks тепер запускається також при змінах `lib/`
і `pubspec.*`, щоб реальний Chromium перевіряв нову збірку в GitHub CI.
Результати CI слід читати за точним source SHA/запуском; цей локальний протокол
не підміняє їх. Підписування, магазини й порівняння з конкурентами не проводилися.
