# Якщо стенд не працює

| Ознака | Що перевірити |
|---|---|
| Немає COM-порта | USB-кабель має передавати дані; перевір плату/драйвер у диспетчері пристроїв Windows |
| Port busy / access denied | Закрий Serial Monitor, іншу діагностику, міст або панель на тому самому порту |
| Немає INFO 2 | Звір порт і прошивку Mega; не вибирай порт радіовузла замість Mega |
| Немає INPUTS 1 | Потрібна прошивка Mega v0.3 з комплекту; v0.2 не містить діагностики входів |
| FAULT одразу | Перевір NC/COM трьох ланцюгів; непідключений або обірваний вхід означає 1 |
| Натискаєш лівий, змінюється правий | Звір D26/D27 та маркування; не виправляй це вимкненням захисту |
| JOG відхилено | Спочатку STOP; JOG дозволено лише в DISARMED, стоп має бути відпущений |
| Неправильний напрямок | Без антени звір JOG; за потреби зміни MOTOR_REVERSED і проший повторно |
| ARM не знаходить нуль | STOP, моторне живлення вимкнути; звір кінцевик, напрямок, муфту та діапазон |
| Мотор гуде чи пропускає кроки | STOP; звір 5V, спільну GND, послідовність IN1..IN4, навантаження та підшипник |
| Павербанк вимикається | Перевір режим малого споживання за інструкцією конкретного павербанка; положення після обриву недостовірне |
| PROBE не дає ACK | Звір власний peer, окремий радіопорт, однаковий канал/ключ/preset і штатні антени; ACK треба фізично перевірити |
| SCAN недоступний | Потрібні radio-режим, успішний PROBE і HOMED; motor-режим не підставляє вимірювання |
| Панель не відкривається | Відкрий повне локальне посилання з термінала на цьому самому ноутбуці; не файл index.html |
| Зупинка після згортання вкладки | Heartbeat браузера міг припинитися; перевір стан і повтори ARM за потреби |
| Кут не відповідає механіці | Номінальні кроки не є енкодером; перевір пропуски, передачу та калібрування |
| Пошук не поліпшує сигнал | Перевір спрямовану антену саме 868 MHz, сталі умови й розташування; сильний RSSI не доводить дальність |

Стоп-кнопка цього стенда — програмний NC-вхід. Фізичне зняття живлення мотора:
від’єднати його USB від павербанка. Не тримай руки в механізмі під час руху.
