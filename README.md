# AMID Offgrid Mobile — 0.2.0

Один Flutter-застосунок для Android та iPhone: локальні матеріали, офлайн-помічник, карти та прямий зв’язок між телефонами. Інтерфейс українською, світла й темна теми. Мобільні збірки виконують Dart/native код; WebView не використовується.

## Що реалізовано
- Довідник: локальний SQLite, Unicode FTS4/FTS5, читання й пошук; імпорт TXT/MD та AMID JSON.
- Локальний ШІ: llama.cpp через llamadart, GGUF із пам’яті телефона, потокова відповідь, скасування, уривки знайдених джерел. Стартова модель Qwen3 0.6B Q8 — 639 446 688 байтів, окреме завантаження з відновленням і SHA-256. Без завантаженої моделі працює чесно позначений пошук.
- Карти: вбудовані реальні контури Natural Earth, імпорт растрових MBTiles і GeoJSON, GPS за запитом, власні точки, передача координат у повідомлення.
- Зв’язок: BLE GATT, ролі host/join для Android/iOS, сполучення секретом через QR або вставлення коду; HKDF-SHA256 + AES-256-GCM, захист від повторів, фрагментація до MTU20, підтвердження лише після збереження повідомлення на приймачі.
- Файли: потокове копіювання великих моделей/карт у приватне сховище; SHA-256, резервна копія текстових даних у JSON, відновлення однією транзакцією.
- Дозволи запитуються для дії користувача. При згортанні зупиняється BLE-сеанс і генерація. Android backup вимкнений; iOS offgrid-каталог виключається з системної резервної копії.

## Межі цієї версії
Це самостійна реалізація функцій. Вона не включає код або облікові записи Kiwix, Organic Maps, PocketPal, Briar чи BitChat.
- ZIM-Вікіпедія, PDF, векторні PBF-карти й розрахунок маршрутів не додані.
- BLE — прямий foreground-сеанс двох AMID, без mesh-ретрансляції й без сумісності з протоколами інших месенджерів.
- З’єднання реальних Android ↔ iPhone та поведінка фонових режимів потребують фізичної перевірки. Дальність не гарантується.
- Вбудована карта світу оглядова, без вулиць. Для деталей потрібен власний MBTiles-пакет із належною ліцензією.
- Qwen 0.6B — компактна модель, якість української й точність відповідей обмежені. Можна імпортувати іншу сумісну GGUF, якщо вистачає RAM.
- Тексти й локальна база не зашифровані окремим паролем. Захист BLE не означає шифрування JSON-експорту або захист від особи з доступом до розблокованого телефона.
- Моделі та MBTiles не входять у JSON backup. Зберігай їхні оригінали окремо.

## Збірка
Поточний SDK: Flutter 3.47.6, Dart 3.13.5. Android minSdk26 (Android8+), arm64. iOS17+.
Потрібні інтернет для першої збірки залежностей і вільне місце для SDK/моделей.

    flutter pub get
    flutter analyze
    flutter test
    flutter build apk --release --target-platform android-arm64

Тестовий APK використовує development/debug signing. Для магазину потрібен власний підпис. У цьому GitHub-репозиторії немає приватних ключів. Нова CI-машина створює свій debug-ключ: така збірка може не встановитися як оновлення старого APK. Перед перевстановленням експортуй текстову резервну копію в застосунку; моделі й карти збережи окремо. Для постійного підпису слід налаштувати власний ключ через GitHub Secrets.

## Через GitHub

Репозиторій: https://github.com/DimasikBog/AMID-Offgrid (приватний).

- Actions → Mobile checks and builds: аналіз, тести й збірка APK на зміни коду в main та pull request.
- Готовий APK і SHA256SUMS.txt: відкрий успішний запуск → Artifacts → AMID-Offgrid-Android.
- Для iOS: Run workflow → увімкни Build unsigned iOS app on macOS. Результат — непідписаний Runner.app у ZIP. Його не можна просто встановити на iPhone: потрібен підпис Apple та перевірка на пристрої.
- Статус саме завантажуваного APK 0.2.0 наведено в RELEASE.json. Результати нових CI-збірок підтверджуються лише зеленим запуском Actions.

Великі моделі, карти користувача, APK та кеші збірки не зберігаються в Git. Готові збірки додаються як вкладення релізів або Artifacts.

## iPhone: завершення на Mac
У Linux iOS/IPA не збиралися. Наявність папки ios не є підтвердженням компіляції Xcode.
1. Встанови сумісний Flutter і Xcode, виконай flutter pub get.
2. Запусти bash scripts/build_ios.sh для перевірки компіляції без підпису.
3. Відкрий ios/Runner.xcworkspace в Xcode.
4. Runner → Signing & Capabilities → обери свою Apple-команду, за потреби зміни bundle ID com.amid.offgrid.
5. Підключи iPhone, вибери його як ціль і натисни Run. Для TestFlight/App Store: Product → Archive → Distribute App зі своїми Apple-обліковими даними.
6. Перевір доступ до Bluetooth, камери, GPS, імпорт із Files та обмін із Android. В архіві перевір PrivacyInfo.xcprivacy у Runner/llama.framework. Дані privacy/export compliance перед публікацією мають відповідати фактичній збірці.

llamadart_llama_cpp_flutter підключає Apple XCFramework через SwiftPM. Пріоритетний шлях — SwiftPM. Не підмінюй runtime невідомими dylib.
Первинна документація: https://llamadart.leehack.com/docs/platforms/apple-setup

## Як перевірити на двох телефонах
1. Установи AMID на обидва телефони; увімкни Bluetooth.
2. На першому: Зв’язок → Створити сеанс. QR містить секрет, показуй лише співрозмовнику.
3. На другому: Сканувати QR → вибрати AMID зі списку.
4. Після статусу «Телефони з’єднані» збережи повідомлення та натисни «Передати поруч».
5. «Отримання підтверджено» означає отриманий зашифрований ACK після запису на іншому пристрої. «Чернетка» не означає передачі.
6. Повтори у зворотному напрямку. Спробуй довгий текст, розрив з’єднання, новий сеанс. Під час тесту тримай обидва застосунки відкритими.

## Формат пакета знань
Дивись examples/my_pack.json. Поля format/version/id/title/license/articles обов’язкові.
Одна стаття: id, title, body, необов’язкові category/source. Для GeoJSON додай map: FeatureCollection або імпортуй сам .geojson.
Розміри: до32MiB текстового імпорту, до64MiB локальних текстових даних, до8GiB бінарного файла. GGUF і MBTiles копіюються потоком.
