# AMID Offgrid 0.5.0

Спільний Flutter-застосунок для Android, iPhone і комп’ютерів та вебверсія:
локальні знання, нотатки, обране й резервні копії. Нативні платформи додають
GGUF та MBTiles; прямий BLE-чат увімкнений лише на Android/iPhone. Український
інтерфейс, системна/світла/темна тема. Окремі мініпрограми — для годинників.

**0.5.0+7 — публічна тестова бета.** [Пакети для восьми платформ](https://github.com/DimasikBog/AMID-Offgrid/releases/tag/v0.5.0-beta.7)
опубліковано після успішної повної матриці CI. Власний код — MIT.
Windows/Linux додатково пройшли перевірку SQLite-збереження у CI;
фізичні пристрої, Apple signing та магазини залишаються неперевіреними.

[Відкрити вебдодаток](https://dimasikbog.github.io/AMID-Offgrid/).
На iPhone відкрий у Safari та додай на головний екран через меню поширення.
Вебверсія не потребує Apple-підпису, але не має нативних GGUF, BLE та MBTiles.
Офлайн-перезапуск на iPhone ще потрібно перевірити.

Вихідний код: https://github.com/DimasikBog/AMID-Offgrid · [MIT](LICENSE).
Завантаження коду не потребує ключів підписування. Великі моделі, карти й
особисті дані не входять у Git; сторонні компоненти мають власні ліцензії.

- Збережений масштаб читання, копіювання тексту та особистий чеклист у backup.
- Легкий режим інтерфейсу: модель вивантажується, BLE-сеанс зупиняється; нотатки й обране залишаються.
- Native Windows/Linux/macOS hosts, desktop SQLite FFI та окрема перевірка тимчасового сховища через `--self-test`.
- Web/PWA із власним кешуванням локального renderer після першого завантаження.
- Окремі Kotlin/Wear OS та SwiftUI/watchOS мініпрограми: 6 офлайн-карток і 6 особистих позначок, без телефонної синхронізації.
- MIT для власного коду, інструкції внесків і публікація перевірених beta-пакетів у GitHub Releases.

## Основні функції

Довідник зберігає матеріали в SQLite та шукає текст локально. Підтримуються
TXT, MD, AMID JSON і GeoJSON. Стартові матеріали вже всередині.

Помічник використовує llama.cpp через llamadart. Додай сумісну GGUF або
завантаж Qwen3 0.6B Q8 з відновленням і перевіркою SHA-256, а потім натисни
«Запустити на телефоні» у пакетах. Без моделі працює чесно позначений пошук.
Генерація, скасування й пам’ять на реальному телефоні ще потребують перевірки.

Карта містить оглядові контури світу Natural Earth. Для вулиць імпортуй
власну растрову MBTiles з належною ліцензією. GPS запитується після дії
користувача. Можна додавати, редагувати та передавати власні точки.

Зв’язок — прямий foreground BLE-сеанс двох AMID з QR/секретом сполучення,
AES-GCM, HKDF, захистом від повторів і фрагментацією. Доставку підтверджує
збереження на приймачі. Після розриву потрібний новий сеанс. Перевірка
Android ↔ iPhone радіоканалу залишається відкритою.

## Android

Actions → **Mobile checks and builds** → успішний запуск → Artifacts →
AMID-Offgrid-Android. Усередині APK, release-manifest.json та SHA256SUMS.txt.

Це development-підпис для тестування. Він може відрізнятися між машинами CI,
тому перед потрібним перевстановленням експортуй копію; моделі й карти
збережи окремо. Для стабільних оновлень налаштуй постійний власний ключ за
[інструкцією підписування](docs/SIGNING.md). Ручний **Signed Android candidate**
створює APK/AAB лише з потрібними секретами й не публікує їх у магазин.

Поточний обсяг: Android 8+ та ARM64. Повну сумісність мінімальної ОС і
нативних бібліотек потрібно перевірити на пристроях.

## iPhone без власного Mac

Actions → **Mobile checks and builds** → Run workflow → build_ios=true.
macOS CI компілює нативний ARM64-застосунок і пакує
AMID_Offgrid_iOS_unsigned.ipa зі структурою Payload/Runner.app.

IPA **непідписаний**. Для особистого встановлення можна перевірити Windows +
офіційний Sideloadly та безкоштовний Apple Account. Підпис зазвичай діє сім
днів; потрібні поновлення та перевірка збереження даних. Встановлення нової
версії на фізичний iPhone ще не підтверджене.

App Store/TestFlight — окремий шлях із членством, сертифікатом і provisioning.
Власний Mac не потрібний, але ці умови не зникають. Внески не купувалися й не
погоджені. Дивись [SIGNING.md](docs/SIGNING.md).

## Дані та обмеження

Локальна база не захищена окремим паролем. Захищена резервна копія шифрує
експорт; звичайний JSON і GeoJSON містять відкритий текст. GGUF/MBTiles не
входять у копію. Відновлення об’єднує дані з наявними; існуючі знання/точки
зберігаються, нові власні нотатки додаються, конфліктні повідомлення відхиляються.

ZIM-Вікіпедія, PDF, векторні PBF, дорожня навігація, mesh, розпізнавання фото та
сумісність із Kiwix/Organic Maps/PocketPal/Briar/BitChat не реалізовані.
Браузерний перегляд не замінює нативні BLE/GPS/Files/GGUF перевірки.

## Розробка та перевірка

Flutter 3.47.6 / Dart 3.13.5; залежності зафіксовані в pubspec.lock.
Для автоматичних середовищ встановлюй CI=true та FLUTTER_SUPPRESS_ANALYTICS=true.
Windows/Linux використовують sqflite_common_ffi 2.4.7 як runtime-залежність.

```sh
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed lib test
flutter analyze --no-pub
flutter test --no-pub --concurrency 2 --reporter expanded
python3 scripts/check_project.py
python3 -m unittest discover -s scripts -p 'test_*.py'
flutter build apk --release --target-platform android-arm64 --no-pub
```

На Windows для Python можна використовувати python замість python3.
iOS-збірка потребує macOS/Xcode; її запускай через Actions.
